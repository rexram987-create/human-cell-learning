# עולם התא — Human Cell Learning

יישומון PWA לימודי ואינטראקטיבי בעברית, עם עמודים נפרדים, הסברים פשוטים וכפתור ״להעמקה״.

## מה כלול

- 27 עמודי לימוד: היכרות עם התא, 10 מבנים ואברונים, 5 תהליכים, ו־9 סוגי תאים בגוף.
- תא סכמטי עם בחירת אברונים באיור או ברשימה נגישה.
- המחשות תהליכים עם הפעלה, עצירה והתקדמות ידנית, כולל תמיכה בהפחתת תנועה.
- 26 שאלות מקוריות עם הסברים, התאמת אברונים לתפקידים וזיהוי באיור.
- מילון של 32 מושגים; שמירת התקדמות והעדפות במכשיר.
- ערכות צבעים בהירה/כהה, שינוי גודל טקסט, מקלדת ומגע.
- חבילת לימוד ללא אינטרנט, הודעת מוכנות רק אחרי שמירה מאומתת, והתקנת PWA.

## הפעלה

Node.js 24 והגרסה הנעולה בקובץ package-lock.json.

```sh
npm ci
npm run dev
npm test
npm run build
```

פלט הייצור הוא `dist/`. בנייה יוצרת רשימת נכסים וגרסת Service Worker מהתוכן שבפלט. יש לפרוס את כל התיקייה יחד, בלי לערבב קבצים מבניות שונות.

## מסלולים

בית `/`, קטגוריה `/category/:categoryId`, שיעור `/lesson/:lessonId`, תא אינטראקטיבי `/explore`, תרגול `/practice`, מילון `/glossary`, מקורות `/sources`, והגדרות/התקנה `/settings`. הגדרות Vercel מפנות עמודי לימוד ל־index.html ומחריגות נכסים סטטיים ומודולי PWA.

## מידע ותמונות

ויקיפדיה משמשת מקור בסיסי; התוכן נבדק מול מקורות מדעיים פתוחים של NHGRI, NCI ו־OpenStax. תאריך הבדיקה: 11.10.2026; אין עדכון אוטומטי. מקורות וקישורי גרסאות נמצאים ב־src/content/sources.json ומופיעים בעמודי הלימוד. לא נעשה שימוש מאומת ב־OpenEvidence מפני שהגישה אליו לא הייתה זמינה, והמשתמש אישר את החלופה.

חמש תמונות רפואיות מקומיות הן של Servier Medical Art ברישיון CC BY 4.0. ייחוס ורישיון פרטניים נמצאים ב־src/content/assets.json, בעמוד המקורות וב־ATTRIBUTION.md. התא האינטראקטיבי הוא איור מקורי סכמטי; הוא אינו צילום או מודל תלת־ממדי. הטקסט שעובד מוויקיפדיה זמין ברישיון CC BY-SA 4.0, עם קרדיט לתורמים וקישור לערך ולגרסה. גופן Heebo מופץ עם רישיון OFL.

## שמירה והתקנה

התקדמות נשמרת מקומית בלבד. ניקוי נתוני האתר עלול למחוק את ההתקדמות ואת חבילת הלימוד. כשל בשמירה מוצג למשתמש ואינו מונע לימוד. כפתור התקנה מופיע כשהדפדפן מאפשר, אחרת מוצגות הוראות. קישורי המקורות החיצוניים דורשים אינטרנט.

גרסה חדשה של היישומון לא מפעילה רענון באמצע תרגול; המשתמש בוחר מתי לעדכן. חבילת לימוד חדשה שלא הורדה במלואה אינה מסומנת כמוכנה ואינה מחליפה חבילה קודמת תקינה.

## אימות

בדיקות Vitest מכסות תוכן וקישורים, עמודים והרחבה, בחירת אברונים, בקרת תהליכים, שמירה פגומה או חסומה, שאלות ומשוב, תרגול מלא, שמירת נכסים ותחזוקת מטמון, והחרגות נתיבי נכסים ב־Vercel. TypeScript ובניית הייצור נבדקים באמצעות npm run build.

בדיקת דפדפן חזותית והתקנה אמיתית בטלפון טרם בוצעו בסביבה זו. בדיקות DOM ומטמון אוטומטיות אינן תחליף מלא לבדיקת PWA בטלפון.
